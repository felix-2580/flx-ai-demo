How to use FLX.AI
  • Type: Enter a question or command in the message bar and press Enter or Send.
  • Use your voice: Select the small glowing reactor beside the message bar, allow microphone access, then speak.
  • Try examples: Choose a suggestion below the message bar, or open Default Commands on the left.
  • Web research: Ask for latest news, current information or weather. Open Sources to visit the referenced pages.
  • Windows controls: Start FLXAI-Companion.exe on the same Windows PC. The status at the top shows whether it is connected.
Reactor guide
  • Blue — processing or speaking
  • Purple — listening
  • Green — command completed
  • Red — something went wrong
  • Default blue — ready for a new request
